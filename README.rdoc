= Redmine（飞书任务同步版）

基于 {Redmine}[https://www.redmine.org]：在 Redmine 里建问题、改状态、改内容，会同步成飞书任务。飞书里改任务 *不会* 写回 Redmine。

更细的镜像与数据说明见 <code>doc/feishu-task-sync.md</code>。

== 怎么用（按顺序做）

=== 1. 准备飞书应用

1. 打开 {飞书开放平台}[https://open.feishu.cn/]，创建 *企业自建应用*
2. 开通权限并 *发布* 到本企业：
   * <code>task:task:write</code>（创建/更新/删除任务、加人）
   * <code>contact:user.id:readonly</code>（用邮箱查用户；没有邮箱可跳过，改用默认 open_id）
3. 记下 App ID、App Secret
4. 在开放平台 *API 调试台* 查自己的用户 <code>open_id</code>（<code>ou_</code> 开头）。至少准备一个，否则任务可能创建成功但飞书界面找不到

=== 2. 启动 Redmine

生产（替换已有官方 SQLite 容器，保留原账号和问题）：

1. 使用 linux/amd64 镜像 <code>redmine-feishu:latest</code>（不要用 Mac ARM 打的包）
2. compose *只改* <code>image: redmine-feishu:latest</code>
3. *不要改*：volume 名字、挂载路径、<code>REDMINE_SECRET_KEY_BASE</code>
4. *不要* 执行 <code>docker compose down -v</code>

  docker load < redmine-feishu.tar.gz
  docker compose up -d

官方镜像不读 <code>REDMINE_DB_SQLITE</code>。真正的库文件是：

  /usr/src/redmine/sqlite/redmine.db

compose 里即使写着 <code>redmine.sqlite3</code> 也可以留着，本镜像同样只用 <code>redmine.db</code>。

本机从源码构建再导出：

  docker compose build
  docker save redmine-feishu:latest | gzip > redmine-feishu.tar.gz

compose 示例（端口、密钥、volume 按你现网填写）：

  services:
    redmine:
      image: redmine-feishu:latest
      container_name: redmine-app
      restart: always
      ports:
        - "12323:3000"
      environment:
        REDMINE_SECRET_KEY_BASE: <必须和原来相同>
      volumes:
        - redmine_sqlite_data:/usr/src/redmine/sqlite
        - redmine_files_data:/usr/src/redmine/files
  volumes:
    redmine_sqlite_data:
    redmine_files_data:

可选环境变量（优先于后台填写）：<code>FEISHU_APP_ID</code>、<code>FEISHU_APP_SECRET</code>、<code>FEISHU_API_BASE</code>（默认 https://open.feishu.cn）。

启动后会自动跑迁移，只加飞书映射表，不会清空用户和 Issue。

=== 3. 打开同步（正式站要再配一遍）

本地配过的开关 *不会* 带到生产库。用 *管理员* 登录 *当前这套* Redmine：

1. 打开 *管理 → 设置 → 集成*
2. 勾选「启用飞书任务同步」
3. 填写 App ID、App Secret（若没用环境变量）
4. 「默认飞书用户 open_id」填一个或多个，逗号、空格或换行均可，例如：

     ou_aaa
     ou_bbb, ou_ccc

5. 填写「飞书任务中的 Redmine 访问地址」，例如 <code>http://118.178.179.139:12323</code>（不要末尾斜杠）。不要用 <code>http://localhost:3000</code>，否则飞书里点不开。
6. 保存
7. 打开要同步的 *项目 → 设置 → 模块*
8. 勾选「飞书任务同步」并保存。每个项目都要勾，只开全局不够

=== 4. 日常操作

在已勾选模块的项目里：

* 新建问题 → 飞书出现对应任务
* 改标题、描述、状态、日期、指派人 → 飞书任务跟着改
* 关闭问题 → 飞书任务完成；重新打开 → 取消完成
* 删除问题，或改成私有 → 删除飞书任务

飞书标题形如 <code>#35 [进行中] 标题</code>，正文第一行是状态，后面是描述。

已有问题不会自动全部推过去，对旧问题 *再保存一次* 才会同步。私有问题不同步。

指派人有飞书邮箱时会加为任务成员；无论是否匹配成功，默认 open_id 列表里的人都会加入。

到飞书「任务 / 我的任务」查看。

== 日志怎么看

  docker logs -f redmine-app

改完问题后：

* <code>Feishu sync running issue=35</code>：已执行同步
* <code>global=false</code>：未开「启用飞书任务同步」
* <code>module=false</code>：当前项目未勾选模块（最常见）
* <code>failed:</code> / <code>error:</code>：App ID/Secret、权限或网络有问题

同步失败只写日志，Redmine 里照样能保存问题。

其它：

* 日志成功但飞书看不到：默认 open_id 未填/填错，或应用权限没发布
* 换镜像后像空站：连错库文件，或动了 volume / 密钥。换回官方 <code>redmine:latest</code> 能恢复则数据还在
